Loadr Support

Thanks for using Loadr. If something doesn't work as expected, write to teamflexkit@gmail.com with:

  • your macOS version and Mac (Apple silicon or Intel);
  • the address of the download, if you can share it;
  • what you expected and what happened.

You'll get an answer within a few days.

Common questions

A download won't resume.

Some servers don't support resuming. Loadr then uses one connection, and an interrupted download starts over. If the file on the server changed since the download began, Loadr also starts over, so you never get a file mixed from two versions.

It's not faster than my browser.

More connections only help when the server limits each connection's speed. Some servers allow only a few connections; Loadr notices and uses fewer. Your internet connection is always the upper limit.

Can it download videos from streaming sites, torrents or FTP?

No. Loadr downloads direct links to files over HTTP and HTTPS.

Where are my files?

In your Downloads folder unless you chose another one. In a finished download's window, click "Show in Folder".

How do I limit the speed?

For everything: Options → Connection → Speed limiter. For one file: open its window, click "Show details" and switch on "Limit".
